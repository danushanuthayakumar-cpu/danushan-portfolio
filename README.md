# Danushan Uthayakumar — portfolio website

A responsive, interactive, static portfolio built with HTML, CSS, and JavaScript.

## Preview locally
Open `index.html` in your browser. The portfolio includes interactive experience filters, an education section featuring the BBA + BMath double degree and 4.0 high-school GPA, animated sections, a responsive mobile menu, reading progress, and a copy-email button.

## Publish for LinkedIn (free)
1. Create a GitHub account and a new public repository named `portfolio`.
2. Upload `index.html`, `styles.css`, `script.js`, and `resume.pdf` from this folder.
3. In your repository, go to **Settings → Pages**. Under **Build and deployment**, select **Deploy from a branch**, then choose `main` and `/ (root)`.
4. GitHub Pages will show your public link (typically `https://YOUR-USERNAME.github.io/portfolio/`).
5. Add this link to your LinkedIn **Featured** section and **Contact info → Website**.

## Customize
- Edit text and dates in `index.html`.
- Adjust appearance in `styles.css`.
- Replace `resume.pdf` with an updated résumé whenever needed.
- To link your actual LinkedIn profile, add its URL to the navigation or contact section. No profile URL was invented.
